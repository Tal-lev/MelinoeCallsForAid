## [1.0.0] - 2026-11-22

<!--Releasenotes start-->
### Patch Highlights:

- Added **Nemesis** as a Playable character, complete her own attacks and animations.
- Added fifteen Nemesis Cast boons.
- Added six Nemesis specific Hammers.
- Added Chronos specific **Hexes** with their accompanying talents. Chronos can no longer use Melinoe's Hexes.
- Added two more Chronos specific Hammers. Chronos can no longer use Melinoe's Hammers.
- Added Nemesis and Chronos Portraits in conversations, Compatible with Zagreus Journey and MelSkin.

Other fixes and improvements:

- Added many Nemesis contextual quips, (150+ in game).
- Added many Chronos contextual quips, (250+ in game).
- Added minor prophecies for Nemesis and Chronos.
- Added Nemesis Arachne Costumes.
- Added Rival Melinoe when playing as Nemesis.
- Added Chronos Mana UI - Mana Symbol and Charge animations by @Yegitu on discord.
- Added Hammer Icons for Chronos and Nemesis by @Yegitu on discord.
- Added Death Defiance Icons for Chronos and Nemesis by @Yegitu on discord..
- Added Keywords description to explain kit changes.
- MelSkin costumes now unlock through gameplay.
- Added a new Unlockable Bearded Chronos Melskin costume.
- Added a new Unlockable Scarless Chronos Melskin costume.
- Added a new Unlockable Slanesh Nemesis Melskin costume.
- Remove Chronos incompatible Dash boons.
- Remove Nemesis incompatible Cast boons.
- Added Chronos and Nemesis related-Cosmetics.
- Added a new type of cosmetic, the "Altar of Ashes Floor Light". A variant of it can be unlocked through the mod now.
- Added a Chronos chid by @burn on discord
- Added Chronos and Nemesis Arcana Card Backs.
- Added Chronos and Nemesis Harvesting Animations.
- Added more Chronos Room transition Animations.
- Removing NPC Chronos from transition into alternate possibilities.
- Added Chronos and Nemesis Biome Map transition.
- Added Chronos petting animation.
- Added New characters to bat menu.
- Modified Nemesis and Heracles encounter text to track new characters instead of Melinoe.
- Balancing: Attack, Omega Attack and Omega Special now stun enemies.
- Balancing: Increased Omega Attack Mana Cost 20->30 
- Balancing: Reduced Omega Special Mana Cost 30->20
- Balancing: Increased Omega Attack Charge time 0.2s->1s
- Balancing: Shifted new characters in the shop to the weapon menu and Removed Chronos Aspect ranks 2-5. 
- Fixed: Chronos always sounds the same when hurt.
- Fixed: Special boons cause Chronos Special to have Melinoe's special VFX.
- Fixed: the game crash when gaining a pom with some of the Chronos dash boons.
- Fixed: Interaction animation lead to Chronos animation glitching.
- Fixed: Hero unexpected size Change during Zagreus Journey biomes
- Fixed: Chronos Omega Attack fires even when there is not sufficient mana.
- Fixed: Chronos Omega Attack sounds like Melinoe.
- Fixed: Chronos sprints if holding the direction button during and after dash.
- Fixed: Circe Word of Greater Girth makes Chronos and Nemesis smaller.
- Fixed: Purchasing Chronos for the first time no longer cause visual glitches.
- Reworked the Readme.md
- DEV: reorganized the scripts per character.
