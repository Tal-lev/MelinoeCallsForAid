# MelinoeCallsForAid

A Hades II mod that allows you to play as other Characters.

## Features

### Chronos 

<div style="display: flex; justify-content: space-between; margin-bottom: 8px;">
  <img src="https://media.githubusercontent.com/media/Tal-lev/MelinoeCallsForAid/refs/heads/main/images/Chronos.PNG" alt="PonyDressList" width="70%">
</div>

- requires reaching the True Ending.
- Move-set
  - Attack is a 2-move Scythe combo.
  - Omega Attack is throwing the Scythe.
  - Special is a non-damaging Vacuum which pulls enemies in.
  - Omega Special is a wide straight projectile which flies the long distance.
  - Cast stops time.
  - No Omega Cast.
  - Dash is a single long distance Teleport.
  - No sprint
- Exclusive Dash boons
- Exclusive Hammers
- Exclusive Hexes

### Nemesis

**Nemesis is still experimental.**

<div style="display: flex; justify-content: space-between; margin-bottom: 8px;">
  <img src="https://media.githubusercontent.com/media/Tal-lev/MelinoeCallsForAid/refs/heads/main/images/Nemesis.PNG" alt="PonyDressList" width="70%">
</div>

- Requires deepening the bond with her.

- Move-set
  - Attack is 3-move sword combo
  - Special is Circular blast which knock enemies back.
  - Omega Special is a larger and stronger Circular blast which knock enemies back.
  - Cast is a parry.
  - No Omega Cast.
  - Dash is Very short and fast
  - Sprint is faster than Melinoe.
- Exclusive Cast boons
- Exclusive Hammers

## Missing Art [Artists Wanted]

## Installation

Use r2modman by ebkr from Thunderstore or GitHub.

While the mod has been tested decently well it is recommended to backup your save from %USERPROFILE%\Saved Games\Hades II\Profile*.sav in case there are issues.
