# MelinoeCallsForAid

A Hades II mod that allows you to play as other Characters.

## Features

- Adds Chronos as a playable Character, requires reaching the True Ending.
  - Move-set
    - Attack is swinging the Scythe in a 2-move combo.
    - Omega Attack is throwing the Scythe.
    - Special is a non-damaging Vacuum which pulls enemies in.
    - Omega Special is a wide straight projectile which flies the long distance.
    - Cast stops time. 
    - Dash is a single long distance Teleport.
    - No sprint
  - Exclusive Dash boons
  - Exclusive Hammers
  - Exclusive Hexes
    
- Adds Nemesis as a playable Character, requires deepening the bond with her.
  - Nemesis is still experimental.
  - Move-set
    - Attack is 3-move sword combo
    - Special is Circular blast which knock enemies back.
    - Cast is a parry. 
    - Dash is Very short and fast
    - Sprint is slightly faster than Melinoe.
  - Exclusive Cast boons

## Missing Art [Artists Wanted]

  - New Hammer Icons

## Installation

Use r2modman by ebkr from Thunderstore or GitHub.

While the mod has been tested decently well it is recommended to backup your save from %USERPROFILE%\Saved Games\Hades II\Profile*.sav in case there are issues.
